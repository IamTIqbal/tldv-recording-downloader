Google Chrome

About a minute

Chrome only allows one-click installs from its paid Web Store, so this one takes 4 steps:

  1. Download recording-downloader-…-chrome.zip from the latest release, then unzip it.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped recording-downloader folder.
  4. Pin it: click the puzzle-piece icon, then the pin.
Download for Chrome

Keep the unzipped folder, because Chrome loads the extension from it.

How to use it: open a recording on tldv.io, click the extension icon, then Download recording.
